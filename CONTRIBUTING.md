# Contribution policy

Transcripts for Omarchy is a personal project maintained by David Fano and shared
publicly for others to use and adapt.

## Pull requests and contributors

This repository is **not accepting pull requests, patches, or outside
contributors at this time**. Please do not open a pull request or start work
expecting it to be merged. Unsolicited pull requests may be closed without review.

You are welcome to fork the project and maintain your own changes under the
[MIT license](LICENSE). This contribution policy does not change the license.

## Support

Support, feature requests, and a release schedule are not guaranteed. Never post
private transcripts, audio, or credentials in public discussions or reports.

If contributions are opened in the future, this policy will be updated first.
